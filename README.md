# AltStore / SideStore Source

收录 [TiebaPure](https://github.com/infinityf4p/TiebaPure-iOS/releases)、[EhPanda](https://github.com/EhPanda-Team/EhPanda/releases)、[NeoBili](https://github.com/Fab1e2000/NeoBili/releases)、[AirSIM](https://github.com/kai-wu-cortex/AirSIM/releases) 和 [HGhub](https://github.com/LNPANDY/HGhub-MacOS-iOS-Version/releases)，每 6 小时自动更新，包含预发布版本。AirSIM 使用不含 Apple Watch 的 sideload 版本；从 v0.9.8.21 开始收录，以匹配当前 Bundle ID。HGhub 仅收录 iOS IPA，不包含 macOS 版本。

在 SideStore 的 **Sources → +** 中添加以下地址，然后选择应用安装：

```text
https://raw.githubusercontent.com/Apocalypsor/altstore-apps/release/source.json
```
