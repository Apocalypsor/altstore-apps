# AirSIM icon

`icon.png` is the original iPad app icon extracted from
[AirSIM v0.9.8.24](https://github.com/kai-wu-cortex/AirSIM/releases/tag/v0.9.8.24),
`AirSIM-iOS-0.9.8-build175-sideload-unsigned.ipa`, at
`Payload/AirSIM.app/AppIcon76x76@2x~ipad.png`.
Apple's optimized PNG encoding was converted to standard PNG with `sips`.

The icon is used to identify the upstream app in this unofficial source.
